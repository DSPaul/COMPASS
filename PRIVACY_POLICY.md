# Privacy Policy

_Last updated: 2025_

## Overview

COMPASS is a local desktop application. Your collection data never leaves your machine. The only data COMPASS may transmit is an optional crash report when the application encounters an unexpected error.

## Crash Reports

### What is collected

When COMPASS crashes, you are given the option to submit an anonymous crash report. That report contains:

- **Application version** — the version of COMPASS that crashed
- **Operating system** — a description of your OS and version (e.g. "Windows 11 Build 22631")
- **Error details** — the exception type, message, and stack trace

No file contents or collection data are included. Stack traces may incidentally contain local file system paths (e.g. the installation path of COMPASS itself).

### Why it is collected

Crash reports are used solely to diagnose and fix the bug that caused the crash. They are not used for analytics, advertising, or any other purpose.

### Where it goes

Crash reports are sent to the COMPASS API (`compassapp.info`), operated by the author of COMPASS (Paul De Smul).

### How long it is kept

A crash report is retained until the underlying bug has been identified and fixed, after which it is deleted.

### Consent

The crash report dialog presents a **Submit an anonymous crash report** option that is checked by default. You can uncheck it before closing the dialog to skip submission. No crash data is ever sent without you first seeing and confirming the dialog.
